# Support

Use GitHub Issues for:

- reproducible bugs;
- feature requests;
- format extraction failures;
- device-specific behavior;
- documentation corrections.

Before opening an issue, include:

- app version or commit;
- platform and OS version;
- device model, when relevant;
- whether the URL is public, private, playlist, or login-required;
- selected output format;
- relevant logs with cookies, tokens, and private URL parameters removed.

Do not post account cookies, passwords, private links, or copyrighted media
files in public issues.
